# 变现方案：广告接在哪、怎么接

> 结论先行：**H5 负责传播，小程序负责赚钱。** 现在这个 H5 放在 GitHub Pages 上，零成本、零服务器，适合先验证"朋友圈愿不愿意传"。一旦数据证明能传，就把同一套体验搬进微信小程序，用「流量主」接微信官方广告，再加品牌赞助和实物海报两条线。

## 1. 为什么不做"分享后才能导出"

- 微信《外部链接内容管理规范》把"分享后才能继续、分享后才能看到结果、分享后才能领取"列为**诱导分享**。一旦被判定，整个域名的链接都会在微信里被拦截，前面积累的传播全部归零。
- 技术上也做不到：网页没有办法确认用户"真的分享了"。微信早就不再把分享成功的回调告诉网页。
- 替代做法已经在产品里：
  - 海报**免费高清导出**。海报右下角印了二维码，写着"扫码，看看你出生那晚的星空"，扫码直接进入"和 TA 合盘"。**海报本身就是传播载体**，图片发朋友圈不受外链规则影响。
  - **星空合盘**是天然的裂变机制：A 发出邀请 → B 打开后填自己的生日 → 两人都看到结果 → B 再发给别人。这就是当年那些爆款测试 H5 的传播结构，而且完全合规。

## 2. 页面上的广告位（已内置，默认关闭）

| 位置 | 时机 | 形态 |
|---|---|---|
| 「那一夜」信息面板底部 | 用户读完月相、行星、光年之星之后 | 原生卡片（图 + 标题 + 一句话） |
| 合盘结果页，按钮上方 | 看完重合度和文案之后 | 原生卡片 |

开场动画、时光倒流、星空抵达这几个"震撼时刻"**不放任何广告**，这是体验的底线。

配置在 `src/js/config.js`：

```js
ads: {
  provider: 'sponsor',            // 'none' | 'sponsor' | 'adsense'
  sponsor: { tag: '赞助', title: '某某天文馆 · 七夕观星夜', text: '8 月 X 日，带 TA 去看真正的银河', image: 'assets/sponsor.jpg', url: 'https://...' },
},
```

改完 `npm run build` 并推送，就会上线。

## 3. 各渠道对比

| 渠道 | 适合 | 条件 / 限制 | 建议 |
|---|---|---|---|
| **微信小程序 · 流量主** | 国内微信用户（主战场） | 需注册小程序；达到平台要求的累计访问量后申请开通（门槛以官方最新规则为准）。支持横幅、插屏、原生模板、**激励视频** | **主力。** 激励视频是微信官方允许的"解锁"：比如"看一段广告，解锁 4K 打印版海报 / 合盘完整报告" |
| **品牌赞助**（已支持） | 节日档期 | 需要自己谈。天文馆、相机、珠宝、婚恋、旅行（观星游）都是天然客户 | 七夕、520、情人节、跨年、双子座流星雨前后，卖"合盘冠名" |
| **实物海报** | 送礼场景 | 需要打印和装裱供应商，或者淘宝客（CPS） | 星空海报在海外是成熟品类，客单价高；可在海报弹窗加"打印装裱"入口 |
| Google AdSense | 海外华人流量 | **中国大陆加载不了**；要求有自有域名，工具类单页站点容易审核不过 | 只作为海外流量的补充 |
| 百度联盟等国内网盟 | 国内浏览器流量 | 需要 **ICP 备案**的域名 | 有备案域名后再考虑 |

## 4. 迁移到小程序要注意什么

- **个人主体的小程序不能用 `web-view` 嵌入 H5**（需要企业主体，外加业务域名备案）。所以不是"套个壳"，而是要把渲染层搬到小程序的 WebGL canvas 上。
- 可以直接复用的部分：
  - 天文计算（`astro.js`、astronomy-engine）
  - 星表数据（`src/data`）
  - 合盘算法（`hepan.js`）
  - 文案（`facts.js`）
  - 音乐引擎：改成调用 `wx.createWebAudioContext`，结构基本不变
- 小程序的分享能力比 H5 强很多：
  - 能自定义分享卡片的图片和标题（`onShareAppMessage`）
  - 支持分享到朋友圈（`onShareTimeline`）
  - 这两点会直接提升点击率
- 电脑上已经装了「微信开发者工具」，可以直接开工。

## 5. 域名与微信访问

- `*.github.io` 在国内能访问，但速度一般。微信内置浏览器有时会对非备案域名弹出"非微信官方网页"的提示，严重时会拦截。**上线后第一件事：用自己的微信打开链接实测。**
- 如果体验不好：
  1. 换一个干净的自有域名，接上 Cloudflare 或其他 CDN。
  2. 如果做了 ICP 备案，就迁到国内的对象存储加 CDN，速度和稳定性都最好。
- 即使链接在微信里受限，**海报 + 二维码**这条路依然有效：图片在朋友圈里随便发，用户长按识别二维码就能进来。

## 6. 数据：知道哪里在流失

- `src/js/monetize.js` 里的 `track()` 已经在关键节点埋了事件：
  - `start`：点开启
  - `rewind` / `arrive`：看到星空
  - `poster` / `poster_save`：生成、保存海报
  - `share`：分享
  - `invite` / `hepan`：合盘
- 所有事件都不带任何个人信息。
- 在 `config.js` 的 `analytics` 里填上百度统计的站点 ID（国内可用）就会生效。需要重点看的漏斗是：
  - 开启 → 看到星空
  - 看到星空 → 生成海报
  - 合盘邀请 → 被邀请人完成

## 7. 节奏建议

1. **现在**：朋友圈小范围发，看海报保存率和合盘完成率。
2. **有传播迹象**：换自有域名，接上统计。
3. **日活稳定**：开发小程序版，开通流量主，上激励视频"解锁打印级海报"。
4. **节日档期**：主动找品牌谈合盘冠名。
